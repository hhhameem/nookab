3. Description of Service

Nookab is an offline-first vocabulary learning application that allows users to:

  • Add and manage personal vocabulary words
  • Practice words through Flashcard, Quiz, and Spelling modes
  • Track learning progress and statistics
  • Import and export vocabulary data via XLSX files
  • Customize learning preferences and profile settings
  • Optionally auto-fill word details using AI (requires your own Google Gemini API key and an internet connection; off by default)

The App does not require account creation, registration, or any form of user authentication. All core functionality — adding and managing words, the practice modes, statistics, and XLSX import/export — is available without an internet connection. The Developer operates no server and receives no user data. The only external request the App can make is the optional AI Auto-Fill, which you must explicitly enable and which sends the single word you typed from your device directly to Google's Gemini API using your own key (see §9).
